# 多网站文章保存指南

适用版本：**v1.3.0.p**；特性分支：`feat/link-health-batch-parallel`。基于 v1.2.0.p（提交 `245eb10713701b765a4625b971b3b2d468ec967b`）开发。

## 支持范围

| 网站 | 可保存的链接 | 识别方式与边界 |
|---|---|---|
| 微信公众号 | `https://mp.weixin.qq.com/s/…` 或 `/s?…` | 沿用公众号正文、作者、图片与排版适配 |
| 知乎专栏 | `https://zhuanlan.zhihu.com/p/文章ID` | 提取专栏正文、标题、作者及可识别的公式 |
| 知乎回答 | `https://www.zhihu.com/question/问题ID/answer/回答ID` 或 `/answer/回答ID` | 只保存指定回答，不混入其他回答；问题列表需先复制具体回答链接 |
| CSDN | `https://blog.csdn.net/作者/article/details/文章ID` | 保留正文与代码语言，清理复制按钮和代码行号；移动版链接自动规范化 |
| 博客园 | `https://www.cnblogs.com/作者/p/文章ID.html` 或 `/articles/文章ID.html` | `.html` 可省略；提取随笔／文章正文与作者信息 |
| 其他文章网页 | 公网标准 HTTP／HTTPS 单篇文章链接 | 尝试 `article`、`main`、`itemprop=articleBody` 等语义正文，并读取 JSON-LD／网页元数据；首页、列表、搜索页与纯交互应用不保证可识别 |

新增能力位于 `local-archive/` 本地服务，仓库原有浏览器扩展继续保留原版本。

## 手动和飞书自动保存

1. Windows 双击 `启动工具.cmd`；Mac 按 [Mac 安装指南](MAC_GUIDE.md) 启动。
2. 打开 **http://127.0.0.1:17880/**，在“手动保存”粘贴文章链接。
3. 每次最多 100 个不同链接，可以混合多个网站，也可粘贴含链接的文本。
4. 等记录显示“保存完成”，打开 MD、内嵌 HTML、手机长图或电脑长图。

已配置的飞书机器人继续使用同一套连接。给它单聊发送上述链接即可，支持纯文本和富文本中的多个网站链接，网页显示来源、站点和结果。未配置时按 [完整指南](public/guide.html#feishu) 创建机器人。“先测试本地消息处理”可验证本地提取、队列、保存与去重，但不能证明真实飞书消息投递成功。

同一篇专用站点文章的分享参数不会产生重复任务。普通网页仅忽略已知跟踪参数，保留可能影响正文的查询参数。要更新内容请点“重新保存”，会生成新目录。本次没有增加微信个人聊天监听；电脑需要开机、联网、后台保持运行。

## 100 篇批量与并发

手动、消息模拟和飞书每次最多 100 个不同链接；超过 100 篇整批拒绝，请拆分发送。网页提交内容最多 1 MB，飞书还受消息平台自身长度限制。先持久入队，后台逐步处理；不同批次可继续排队。

“保存设置”选择 1–4 篇同时保存，默认 2 篇。同网站最多 2 篇，新采集间隔约 800 毫秒；长图逐篇生成，其余任务可继续采集与下载。并发不保证成倍提速，网络、CPU、磁盘和网站限流都会影响速度。内存较少或显示浏览器人工验证时可设为 1 篇。降低并发后已开始的任务正常完成。

队列显示等待数量与当前并发，最近 300 条记录可见，全部记录在数据库中。收到网站限流提示时，暂停该网站的新任务约 60 秒，其他网站可继续；限流失败的那篇不自动反复重试，请稍后重新保存。

## 失效与公众号迁移

- 明确删除、过期、侵权下架、违规或 HTTP 404／410：显示“链接已失效”，网页汇总提醒，不保存错误页。恢复后可重新保存。
- “该公众号已迁移”：读取微信提供的“访问文章”链接，规范为 HTTPS，自动继续保存；最多 5 次，循环与站外目标停止并提示。metadata 的 `original_url`、`resolved_url`、`link_state`、`migrations` 保留来源。
- HTTP 403、验证码、登录与访问频率限制属于需确认或暂时限制，不能据此断言文章已删除。迁移目标需要验证时，记录仍保留新链接；启用“显示采集浏览器”并重试，完成网站正常验证。

用户迁移示例在本机已识别出新文章地址，但新地址进入微信验证页；自动跟随已验证，当前网络的免验证完整保存未验证。自写迁移测试覆盖整条 MD／HTML／双长图保存和二次页面跳转。

## 文件与排版

公众号维持“公众号名称／文章”目录。新站点按“网站／作者（未识别时为域名）／文章”组织：

```text
archives/CSDN/作者名称/日期_文章标题_短ID/
  文章标题.md
  文章标题.html
  文章标题_手机.png
  文章标题_电脑.png
  文章标题_metadata.json
  images/001.png
```

- **MD**：可编辑正文，保留标题、列表、引用、代码语言、表格及可识别的 LaTeX；原图字节存放在 `images/`，使用相对引用。移动 MD 必须带走图片目录。
- **HTML**：图片和样式内嵌，可独立断网阅读、点击查看原图。新站点保留选中正文 DOM 和主要字体、颜色、间距、代码样式，移除导航、推荐、评论、悬浮工具条，标题与作者使用统一阅读容器。公众号沿用原页面归档。
- **两张 PNG**：手机 432×768、电脑 1280×720 阅读窗口重新排版，默认 3 倍设备像素，逐屏采集并验证接缝，无损编码。比例指窗口，整篇长图高度取决于文章长度。
- **metadata**：新增 `site`、`site_name`、`article_kind`、`extraction`，记录站点、文章／回答类型和正文选择方式。JSON 的 `platform` 仍表示运行系统；MD 的 Front Matter 中 `platform` 表示来源站点。

Markdown 的字体、颜色和间距由阅读器决定，以 HTML 为准。新站点输出是正文阅读版；宽度变化会重新换行。

## 人工确认与失败提示

- **HTTP 403、验证码、登录或付费限制**：任务显示“需要人工确认”，不会把错误页／登录页冒充文章。确认正常浏览器能访问后，可在“保存设置”启用“显示采集浏览器”，重试并在采集窗口完成正常登录／验证；等待正文最长约 90 秒。
- **普通网页无法识别单篇正文**：改用具体文章链接；无法识别时明确提示，不保存整张首页。
- **部分图片失败**：保留已生成文件并提示；MD 保留失败图片原链接，metadata 记录原因。该结果不算完整离线，网络恢复后可重试。
- **视频、音频或互动图表**：仅保存可见静态内容，不保留播放和脚本交互。
- **原先“正文超出阅读宽度”**：部分长公式 SVG 使用 `max-width:300%!important`，嵌套代码保持不换行，展开溢出后造成页面超宽。本版在截图阅读窗口内按 SVG viewBox 比例缩放，并让整段代码换行；不删公式、不裁代码、不改 MD 和原 HTML。还存在无法排版的极端内容时，错误提示增加元素类型，便于定位。

采集浏览器不继承日常浏览器登录状态，本版不持久化网站 Cookie；登录文章可能每次都需要人工验证。不宣称绕过访问控制或支持所有网页。

## 验证范围和二次开发

自写测试页覆盖 CSDN、博客园、知乎专栏、指定知乎回答、普通文章：真实浏览器生成全部文件，检查原图字节、MD 结构、HTML 断网图片、双长图覆盖及接缝。另验证混合消息、去重、公网地址校验、列表／验证页／付费提示拒绝、多回答隔离。测试页不含真实网站文章内容。

本次当前电脑实际完成博客园文章和 MDN 中文文档的 MD／HTML／双长图保存，离线检查和接缝检查通过。知乎和 CSDN 在该网络返回 403，不能据此称为真实在线归档已验证。Windows、Apple Silicon Mac、Intel Mac 回归状态见 [GitHub Actions](https://github.com/Er1ckPang/wechat-to-markdown/actions/workflows/local-archive.yml)。

新增站点修改 `src/urls.mjs` 和 `src/sites.mjs`，补充自写测试页；输出由同一 `archive.mjs` 生成。修改本指南或 Mac 指南后运行 `pnpm build:guides`。

## 保存记录和动图

首页显示全库摘要及最前12个正在保存／等待条目。进入[保存记录页](http://127.0.0.1:17880/records.html)，按记录分类、状态、网站、公众号／作者、消息来源、北京时间入队日期和关键词筛选。每页20／50／100条，支持排序、翻页、页码跳转；每次筛选最多查看10000条结果，完整数据库不设此删除上限。可缩小条件查找上限外旧记录。

逐屏长图固定GIF、WebP、APNG首帧，以免动图使上下截图重叠区不一致。固定帧使用源像素，无损编码，仅修改临时截图页面。MD的本地图片和单文件HTML仍保存原始动图字节。
