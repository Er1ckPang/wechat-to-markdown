1.2.0 — 2026-10-06

精简与标题命名
  每篇仅五个文件：标题.md、标题.html、标题_手机.png、标题_电脑.png、标题_metadata.json。
  MD 使用 data URI 引用定义内嵌原图；HTML 内嵌原图与样式，分别可独立携带。
  取消图片目录、其他 HTML 副本与辅助预览页文件；长图阅读页由本地服务临时生成。
  HTML 用纯 HTML/CSS 原图查看层，支持原始尺寸与下载，无需脚本。
  完整标题写入正文和 JSON，文件名非法字符替换、过长标题缩短。

两种长图
  手机按 432×768（9:16）、电脑按 1280×720（16:9）阅读窗口重新排版。
  比例指浏览器窗口；长图高度由正文长度决定。各保存一张，不再分段。
  宽表格在文章宽度内换行，保留所有列；裁掉电脑文章栏外多余空白。
  沿用逐屏实际滚动坐标合成、悬浮工具栏排除、接缝像素检查与无损流式编码。
  默认 3 倍设备像素，无二次缩放；单张超过 50 万像素行明确失败。

版本与服务
  独立目录 wx2md-local-v1.2.0，保留所有旧版与归档。
  页面底部从服务实时获取版本，设置中显示实际程序路径。
  文件接口支持标题命名新归档，同时保持旧版归档访问。
  metadata 格式升级为 4，记录文件名和两种截图的完整覆盖、尺寸、校验信息。
  更新前服务 1.1.1，停止后复制设置和任务库并切换至 1.2.0。

1.1.0 — 2026-10-06

长截图
  默认以 3 倍设备像素比直接渲染并保存无损 PNG，可选 1/2/3/4 倍。
  保持原网页阅读宽度；430 CSS px 对应默认 1290 px 的图片宽度。
  新增 screenshots.html 阅读页，可切换阅读宽度与 100% 像素，支持下载。
  对超长网页或单张截图失败自动分段，保留所选采集分辨率。

HTML 与原图
  original.html 保留原网页 DOM 和 CSS，正文图片引用 images/ 本地原文件。
  点击正文图片可单独打开原图；新增 images.html 原图列表与下载按钮。
  图片保留获取到的原始字节，记录尺寸与 SHA-256，不二次压缩。
  original-singlefile.html 保留图片内嵌版，适合单文件携带。
  本地预览支持图片新窗口与下载，归档页面仍禁止执行脚本。

Markdown
  转换前识别样式粗体、斜体、删除线、下划线和明确的大字号独立标题。
  保留原生标题层级、列表、段落、链接、图片顺序、上下标与代码块。
  读取微信 data-formula/data-latex、TeX annotation 和 MathJax TeX 源。
  行内公式用 $…$，独立公式用 $$…$$；没有 TeX 源的 MathML 保留原标签。
  普通表格转为 GFM，单元格内换行保留为 <br>；合并单元格等复杂表格
  保留 HTML table，避免拆散表格。Markdown 查看器需支持内嵌 HTML。
  新增 markdown.html 阅读预览，优先用原文 SVG 显示公式，无需网络加载。
  Markdown 主要保留内容结构；颜色、字体、间距等原样式请查看 original.html。

版本管理
  新程序独立保存于 wx2md-local-v1.1.0，保留 wx2md-local 1.0.0。
  启动器检查占用端口的程序版本与目录，避免误打开其他版本。
  metadata.json 加入工具版本、PNG 实际尺寸和 Markdown 结构统计。
  当前电脑停止旧版后复制设置与任务库；旧归档保留原位置。
  新源码包为 wx2md-local-v1.1.0.zip，不包含设置、凭据和文章。
