在线文章本地保存 / wx2md Local 1.3.0.p · 2026-10-08

当前电脑：双击本目录“启动工具.cmd”，访问 http://127.0.0.1:17880。
完整手动使用、文件说明、飞书配置和升级步骤见 public/guide.html。
页面底部显示实际运行版本，“保存设置”显示运行目录；/health 也可核对。

每篇五个标题命名文件，加一个 images/ 图片目录：
  文章标题.md              可编辑正文，图片使用 images/001.jpg 等本地相对路径
  文章标题.html            选中正文与样式，图片内嵌，独立离线阅读
  文章标题_手机.png        432×768（9:16）阅读窗口排版后的无损整篇长图
  文章标题_电脑.png        1280×720（16:9）窗口排版，裁掉文章栏外空白
  文章标题_metadata.json   来源、版本、文件名、两种截图参数、校验和检查
标题中的非法字符会替换，过长标题会缩短；完整标题保存在正文和 JSON。
images/ 保存 MD 使用的原始图片字节，重复图片复用编号文件。
移动或备份 MD 时，请连同 images/ 一起移动；HTML 独立携带。
不生成其他 HTML 副本或辅助阅读页文件。

长图比例指阅读窗口，最终高度由文章长度决定。默认按 3 倍设备像素采集，
PNG 不做二次缩放或有损压缩，原图片不重新编码。两种长图各一张；
宽表格在各自阅读宽度内换行，保留全部列，原 HTML 保留原表格方式。
从离线 HTML 逐屏采集，去除悬浮作者栏，按实际滚动位置裁剪重叠，
验证上下接缝后流式无损编码。超出单张 50 万像素行会明确失败。
记录中的长图阅读页面由服务临时生成，不写入归档目录。
HTML 点击图片可用纯 CSS 打开原始尺寸并下载，不需要执行脚本。
MD 保留 LaTeX、原生标题、普通 GFM 表格和复杂 HTML 表格，
阅读器需要支持本地图片路径、数学公式和内嵌 HTML。原样式以 HTML 为准。
图片保存失败会保留原链接并记录提示；该情况不算完整离线。

飞书功能沿用原版：应用官方长连接，接收给机器人的授权单聊文字／富文本。
凭据直接填本地页面；本机需要开机联网。实际飞书收件本次未重新验证。
Mac：支持 macOS 14+ 的 Apple Silicon 与 Intel 64 位。
首次安装 Node.js 24 LTS，然后运行 install-mac.command；以后运行 start-mac.command。
检查用 doctor-mac.command，停止用 stop-mac.command。详细步骤见 MAC_GUIDE.md 或 public/mac-guide.html。
原生自动测试以 GitHub Actions 的结果为准；用户 Mac 的网络与账号权限需实机验收。微信个人聊天监听未启用。

版本与切换：
  更新前服务为 1.2.0.p，本次切换后为 1.3.0.p，使用独立版本目录。
  历史开发目录压缩归档，文章与设置迁入当前版本；本机已经停旧版后复制设置和任务库。
  旧记录的归档路径已迁移到当前版本，新文章默认写入本目录 archives/。
  已保存文件不会自动改写，点“重新保存”才生成 MD 本地图片格式。
  关闭页面不会停止后台。切换：保存设置→停止本地工具→启动新版→刷新页面。
  以后升级也解压到新目录；需继承记录则停旧版后复制 data/config.json
  与 data/jobs.sqlite 到尚未启动的新版 data/，不要覆盖新版已有数据。
  复制的配置可能指向旧保存目录，按需要在新版设置中调整。
  页面刷新不能升级后台；启动器会拒绝复用别的目录或版本服务。

保存记录页：
  首页仅显示摘要及当前活跃任务（最多12条）。
  点击“保存记录”查看全部历史；按分类、状态、网站、公众号/作者、
  消息来源、入队日期、标题/作者/链接关键词筛选，可组合并排序。
  每页20/50/100条，可翻页及跳转；筛选后最多查看10000条结果。
  其余数据仍保留；缩小筛选可以找到默认前10000条以外的文章。
  长图中动图固定第一帧；MD与HTML仍保留原始动图。

微信“去验证”超时备用方式：
  在日常 Edge/Chrome 正常打开文章并滚动加载图片，保存 MHTML 单个文件；
  没有该选项时，用 SingleFile 扩展保存内嵌 HTML。
  首页“从普通浏览器导入”填实际文章链接并选择单文件（最多64MB）。
  后台生成同样五个文件和 images/，不再访问微信验证服务。
  失败记录的导入入口可继续原任务；迁移文章用记录中的新链接。
  普通完整网页的 HTML＋资源文件夹不支持；普通浏览器也打不开时，
  先解决网站访问问题。导入副本仅在私有 data/browser-imports/ 保留供重试。

SingleFile 详细设置见 SINGLEFILE_GUIDE.md / public/singlefile-guide.html。
  格式选 HTML，开启滚动内容保存；不阻止图片、样式表和字体。
  图片缩小系数设为1，保存后先断网检查正文和图片，再导入工具。
  MHTML 的图片地址片段、延迟图片及内置样式已修复，已有导入可重新保存。
