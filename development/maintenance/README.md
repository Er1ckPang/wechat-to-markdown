# 基线整理工具

正式启动入口在 `../../local-archive/`。此目录记录 2026-10-06 的一次性整理操作。

- `migrate-local-data.py`：停止旧服务后复制私人配置、任务库和文章，校验字节，修正任务绝对路径。需要原始旧目录；不应重复运行到已有数据上。
- `archive-history.py`：将约定的旧目录和开发产物压缩，逐文件验证后清理。已有历史总包时只校验并恢复清理，不覆盖总包；只读文件处理受目录范围限制。
- `verify-migration.mjs`：检查当前服务版本、任务、MD、图片、元信息大小和界面；结果写入被 Git 忽略的 data/。
- `write-documents.py`：从已脱敏的可见历史消息生成两份主文档。输入 development-archive-preparation.json 已收进私人历史包；如需重建，先恢复此输入，保留当前人工补充内容。
- `finalize-records.py`：生成公开发布清单，并保存整理阶段辅助代码的脱敏副本。
- `check-staged-source.py`：检查 Git 暂存清单没有私人运行目录、数据库和凭据；只输出统计和违规文件名。

这里的脚本依赖本机约定目录，使用前应阅读源码和历史记录。历史 ZIP 含配置及真实文章，仅留本机。
